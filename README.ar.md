# تطبيق Zvid لتصفح الأفلام والمسلسلات

🌐 **Language / اللغة:** [English (الإنجليزية)](README.md) | **[تحميل تطبيق APK](https://github.com/Zead-zoher/Zvid-/releases/download/v1.0.0/Zvid_v1.0.0.apk)**

**الترخيص:** MIT | **الحد الأدنى للنظام:** Android 7.0 (API 24) | **اللغة الأساسية:** Kotlin | **الإعلانات:** لا يوجد | **خادم البث:** vidsrc.win

تطبيق Zvid هو تطبيق أندرويد أنيق وخالٍ تماماً من الإعلانات لتصفح ومتابعة الأفلام والمسلسلات، تم بناؤه باستخدام لغة Kotlin وواجهات Jetpack Compose الحديثة. يتيح التطبيق للمستخدمين استكشاف الأفلام، والمسلسلات، والممثلين، والشركات المنتجة مع مشغل مدمج وسلس يعتمد على مكتبات AndroidX Media3/ExoPlayer مع دعم خارجي للبث وأجهزة العرض.

## بننية التطبيق وتدفق البيانات

يتبع تطبيق Zvid معايير تطوير تطبيقات أندرويد الحديثة عبر تبني النمط المعماري MVVM (Model-View-ViewModel) بالتوازي مع تدفق البيانات أحادي الاتجاه (UDF). تضمن هذه البنية فصل منطق البيانات تماماً عن واجهات المستخدم الرسومية لضمان سهولة التطوير والصيانة والاختبار.

### خطوات تدفق البيانات
1. **المستودعات ومصادر البيانات (Repository & Remote Sources)**: يتم جلب البيانات الخام من واجهة برمجة تطبيقات TMDB باستخدام Retrofit. يعمل المستودع كمصدر وحيد وموثوق للبيانات، حيث يتولى تحويل كائنات الشبكة الخام (DTOs) إلى نماذج بيانات مخصصة ومبسطة للواجهات الرسومية (Domain Models).
2. **نموذج العرض وحالة الواجهة (ViewModel & StateFlow)**: يقوم الـ ViewModel بإدارة وتحديث حالة التطبيق عبر طلب البيانات بشكل غير متزامن من المستودعات داخل بيئة Kotlin Coroutines. يتم إرسال النتائج عبر حالات `StateFlow` للقراءة فقط ومتوافقة مع دورة حياة التطبيق لضمان عدم حدوث تعديلات عشوائية في الحالة.
3. **واجهات المستخدم الرسومية (Compose UI)**: تقوم شاشات Jetpack Compose بجمع ومراقبة حالات الـ `StateFlow` المصدرة بأمان تام عن طريق `collectAsStateWithLifecycle()`. يتم إرسال أي تفاعل من المستخدم فوراً كحدث إلى الـ ViewModel لتحديث الحالة من جديد، مما يحافظ على أحادية اتجاه تدفق البيانات بشكل كامل.

## الهيكل المجلدي للمشروع

```
app/src/main/java/com/example/
├── data/              # خدمات الشبكة والاتصال، المستودعات المحلية، وإدارة مفاتيح التشغيل
├── player/            # إعداد مشغل ExoPlayer / Media3 والمشغلات الخارجية وأدوات البث
├── ui/                # طبقة واجهات المستخدم الرسومية
│   ├── components/    # العناصر الرسومية القابلة لإعادة الاستخدام (بطاقات، شبكات، أشرطة تصفح)
│   ├── modals/        # واجهات الخيارات (محدد دقة الفيديو، بطاقة الممثل السريعة)
│   ├── screens/       # شاشات العرض الرئيسية (أفلام، مسلسلات، استوديوهات، المفضلة، السجل)
│   └── theme/         # إعدادات المظهر المظلم والألوان ونوع الخط وأشكال الحواف (Material 3)
└── viewmodel/         # نماذج العرض وإدارة حالات واجهة المستخدم والـ StateFlow
```

## المتطلبات وبناء المشروع

**المتطلبات الأساسية:** حزمة JDK 17 | بيئة Android SDK 24 وأعلى (الحد الأدنى Android 7.0) | برنامج Android Studio (إصدار Ladybug أو أحدث)

لبناء وتجميع كود المشروع محلياً على جهازك، قم بتشغيل الأوامر التالية في سطر الأوامر:

```bash
# استنساخ المستودع على جهازك
git clone https://github.com/Zead-zoher/Zvid-.git
cd Zvid-

# بناء وتصدير ملف الـ APK لتثبيته على الهاتف
./gradlew assembleDebug # لأنظمة macOS/Linux
gradlew.bat assembleDebug # لأنظمة Windows
```

## إعداد مفتاح TMDB الرسمي

يعمل تطبيق Zvid مباشرة بمفتاح تجريبي مؤقت. لاستخدام مفتاح TMDB الخاص بك والحصول على أداء أفضل:

1. قم بإنشاء حساب مجاني على موقع [The Movie Database (TMDB)](https://www.themoviedb.org/).
2. انتقل إلى **إعدادات الحساب** -> ثم اختر **API** من القائمة الجانبية اليسرى.
3. قم بطلب مفتاح API جديد بصفتك "مطور" واقبل الشروط.
4. قم بنسخ **مفتاح API الرسمي (v3 auth)**.
5. افتح تطبيق Zvid على هاتفك، اضغط على **أيقونة الترس للإعدادات** (أعلى اليمين)، ثم قم بلصق المفتاح والضغط على **حفظ المفتاح (Save Key)**.

## إخلاء المسؤولية

- **مزودو المحتوى الخارجيون**: لا يستضيف هذا التطبيق أو يرفع أو يخزن أي ملفات فيديو على خوادمه الخاصة. يتم جلب جميع روابط البث ديناميكياً من خوادم ويب عامة وخارجية، وتحديداً من موقع [vidsrc.win](https://vidsrc.win/). تقع المسؤولية الكاملة في اختيار واستخدام محتوى البث على عاتق المستخدم النهائي.
- **بيانات TMDB**: يتم جلب جميع تفاصيل الأفلام، والبوسترات، وسير الممثلين الذاتية من واجهة برمجة تطبيقات TMDB الرسمية. هذا التطبيق هو عميل تصفح غير رسمي ولا يتبع أو يتم اعتماده من قِبل TMDB.
- **خالٍ من الإعلانات**: تطبيق Zvid مجاني بالكامل ومفتوح المصدر لأغراض تعليمية وغير تجارية، ولا يحتوي على أي إعلانات، أو أدوات تتبع، أو ميزات ربحية.
