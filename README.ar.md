# 🎬 Zvid - تطبيق أندرويد حديث للأفلام والمسلسلات

🌐 [English](README.md) | **العربية**

**Zvid** هو تطبيق أندرويد حديث لتصفح ومشاهدة الأفلام والمسلسلات، مبني باستخدام **Kotlin** و **Jetpack Compose**. يعتمد على TMDB API لتصفح الأفلام والمسلسلات وأعمال الممثلين وكتالوجات شركات الإنتاج مع مشغل فيديو مدمج، ويحتوي على نظام فلترة مدمج يعمل دائماً لحماية المستخدم من المحتوى الإباحي **بالعربية والإنجليزية**.

📥 **[تحميل تطبيق Zvid_v1.0.0.apk](https://github.com/Zead-zoher/Zvid-/releases/download/v1.0.0/Zvid_v1.0.0.apk)**

---

## 🌟 أهم المميزات

- 🎬 **تصفح شامل للأفلام والمسلسلات**: الأفلام والمسلسلات الشائعة والأعلى تقييماً والرائجة مع تصنيفات متنوعة ودعم فلترة المناطق (مثل EU & Lat).
- 🛡️ **حماية من المحتوى الإباحي (عربي وإنجليزي)**: نظام فلترة مدمج يعمل دائماً ويحجب المحتوى الإباحي والجنسي (بما في ذلك الهنتاي) باللغتين العربية والإنجليزية. راجع قسم [نظام الحماية](#-نظام-الحماية-من-المحتوى-الإباحي) بالأسفل.
- 🏢 **عرض أعمال شركات الإنتاج**: تصفح كل أفلام ومسلسلات الشركات بدون قيود.
- 🎭 **صفحات الممثلين وفريق العمل**: استعراض السيرة الذاتية والأعمال الكاملة للممثلين مع تنقل سلس بين الصفحات.
- ⏯️ **مشغل فيديو متكامل**: مشغل مبني على AndroidX Media3 / ExoPlayer يدعم اختيار السيرفر وتغيير الجودة والتحكم الكامل في التشغيل.
- 🔖 **قائمة الحفظ والسجل**: حفظ الأعمال المفضلة ومتابعة المشاهدة من حيث توقفت.
- 📺 **دعم Web Video Caster**: إرسال وبث روابط الفيديو مباشرة إلى التلفزيون الذكي عبر تطبيق Web Video Caster.
- 🎨 **واجهة Material 3 داكنة**: تصميم عصري بالوضع الداكن (Dark Mode) مع حركات سلسة وتخطيطات متجاوبة.

## 🛡️ نظام الحماية من المحتوى الإباحي

يحتوي Zvid على نظام فلترة مدمج يحمي المستخدمين من المحتوى الإباحي والجنسي **باللغتين العربية والإنجليزية**.

- **يعمل دائماً**: الفلتر جزء أساسي من التطبيق، ولا يوجد زر لإيقافه في الإعدادات، فلا يمكن إغلاقه بالخطأ.
- **عربي وإنجليزي**: يتم فحص العناوين والأوصاف والكلمات المفتاحية باللغتين، فيتم حجب المحتوى الإباحي سواء كُتب بالعربية أو بالإنجليزية.
- **حجب المحتوى الجنسي فقط**: الفلتر ليس فلتر أعمار، فأفلام الأكشن والعنف (18+) لا يتم حذفها من الكتالوج.
- **قائمة حظر**: يمكن حجب أفلام أو مسلسلات أو شركات إنتاج محددة عن طريق ملف JSON على هذا المستودع يقرأه التطبيق ويخفي منه هذه الأعمال.
- **زر الإبلاغ**: لو ظهر محتوى غير مناسب، يمكن للمستخدم الإبلاغ عنه مباشرة من التطبيق ليتم مراجعته وإضافته إلى قائمة الحظر.

## 🛠️ التقنيات المستخدمة

- **اللغة**: [Kotlin](https://kotlinlang.org/)
- **الواجهة**: [Jetpack Compose](https://developer.android.com/jetpack/compose) مع Material 3
- **نمط البنية**: MVVM مع تدفق بيانات أحادي الاتجاه (StateFlow)
- **الشبكة**: Retrofit 2 و OkHttp 3
- **تشغيل الفيديو**: AndroidX Media3 / ExoPlayer
- **تحميل الصور**: Coil Compose
- **العمليات غير المتزامنة**: Kotlin Coroutines & Flow

### البناء من المصدر

#### المتطلبات

- **Android Studio**: إصدار Ladybug / Jellyfish أو أحدث
- **JDK**: الإصدار 17 أو أعلى
- **Android SDK**: الحد الأدنى SDK 24 (Android 7.0)، والهدف SDK 34/35

1. **نسخ المستودع**:

</div>

```
git clone https://github.com/Zead-zoher/Zvid-.git
cd Zvid-
```

<div dir="rtl">

2. **بناء نسخة Debug**:

</div>

```
gradle assembleDebug
```

<div dir="rtl">

3. **إعداد مفتاح TMDB API**:
التطبيق يعمل مباشرة بمفتاح تجريبي مدمج. للاستخدام الشخصي بدون حدود، احصل على مفتاحك الخاص:

   - **كيفية الحصول على المفتاح**:
     1. أنشئ حساباً مجانياً على [The Movie Database (TMDB)](https://www.themoviedb.org/).
     2. اضغط على صورة حسابك ثم Settings.
     3. اختر تبويب **API** من القائمة الجانبية.
     4. اضغط على **Create** واختر **Developer** (مطور).
     5. وافق على الشروط واكتب وصفاً مختصراً للتطبيق (مثال: "Zvid Streaming Android App").
     6. انسخ **API Key (v3 auth)**.
   - **كيفية استخدام المفتاح في التطبيق**:
     * افتح تطبيق Zvid على جهازك.
     * اضغط على أيقونة الترس (الإعدادات) في أعلى اليمين لفتح قائمة الإعدادات.
     * الصق المفتاح في خانة TMDB API Key واضغط **حفظ المفتاح**.
     * أو يمكنك تعديل الملف `com.example.data.local.ApiKeyStore.kt` واستبدال `DEFAULT_DEMO_KEY` بمفتاحك ليصبح هو الافتراضي بشكل دائم.

## ⚖️ إخلاء المسؤولية

- **بدون أي إعلانات**: هذا التطبيق مجاني بالكامل 100% ومفتوح المصدر، ولا يحتوي على أي إعلانات أو أدوات تتبع أو ميزات مدفوعة.
- **معلومات الأفلام والمسلسلات**: يتم جلب جميع بيانات الأفلام والمسلسلات وصور الممثلين تلقائياً باستخدام مفتاح API الرسمي لموقع [TMDB](https://www.themoviedb.org/) والذي يقوم المستخدم بإدخاله بنفسه في إعدادات التطبيق.
- **مصادر البث وتضمين الفيديو**: التطبيق لا يستضيف ولا يرفع ولا يخزن أي ملفات فيديو أو أفلام على خوادمه الخاصة. التطبيق يعمل فقط كواجهة مستخدم لتشغيل الروابط والمشغلات الخارجية المتاحة للعامة (تحديداً من موقع السيرفرات الخارجي [vidsrc.win](https://vidsrc.win/)). أي استفسارات أو شكاوى متعلقة بحقوق الطبع والنشر لملفات الفيديو يجب توجيهها مباشرة إلى السيرفرات الخارجية المستضيفة للمحتوى.
- **فلتر المحتوى**: الفلتر يقلل بشكل كبير من ظهور المحتوى الجنسي، لكن لا يوجد فلتر آلي مثالي. من فضلك استخدم زر الإبلاغ داخل التطبيق للإبلاغ عن أي محتوى يمر من الفلتر.
